# Универ-Ассистент - Чат-бот для цифровизации вуза

Чат-бот для мессенджера MAX с мини-приложением для студентов.

## 🚀 Функциональность

- 📅 Расписание занятий
- 📝 Проектная деятельность  
- 🎓 Сервисы деканата
- 📚 Электронная библиотека
- 🎭 Мероприятия вуза

## 🛠 Технологии

- **Backend**: Python + Flask (размещен на Render.com)
- **Frontend**: HTML/CSS/JS (размещен на GitHub Pages)
- **Мессенджер**: MAX

## 📦 Установка

1. Клонируйте репозиторий
2. Настройте бота на Render.com
3. Настройте вебхук в MAX
4. Мини-приложение автоматически деплоится на GitHub Pages
